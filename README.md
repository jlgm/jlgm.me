# jlgm.me

Single static page. No build step. The only external dependency is the Lato font from Google Fonts.

## Colors

The page palette is the block of `--clr-*` variables at the top of `index.html` (currently cyberpunk). A monochrome alternative is kept in the comment right above it; swap the seven values to switch. The terminal has its own `--term-*` variables and keeps the original green look regardless of page palette.
